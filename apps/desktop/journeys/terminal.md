# Terminal: key user journeys

Agent shell output (placeholder). Start at `http://localhost:6200/web.html?open=terminal`.

| Id  | Who / goal                                                 | Starts at                    | Done when                                                                |
| --- | ---------------------------------------------------------- | ---------------------------- | ------------------------------------------------------------------------ |
| T1  | See at a glance which agents are running, waiting or idle. | `?open=terminal`             | They can name the agent that's waiting for review.                       |
| T2  | Read the output in a narrow window.                        | `?open=terminal`             | The lines wrap and stay readable; there's no sideways scrolling.         |
| T3  | Read it in light mode too.                                 | `?open=terminal&theme=light` | The terminal stays dark and legible, and its title bar text is readable. |

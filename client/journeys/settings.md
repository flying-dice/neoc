# Settings: key user journeys

System preferences. Start at `http://localhost:6200/web.html?open=settings`.

| Id  | Who / goal                                               | Starts at        | Done when                                                                     |
| --- | -------------------------------------------------------- | ---------------- | ----------------------------------------------------------------------------- |
| S1  | Switch to dark mode, then back to automatic.             | `?open=settings` | The whole desktop went dark, then followed the system again.                  |
| S2  | Change the accent colour to green.                       | `?open=settings` | Buttons and selected rows across apps are green.                              |
| S3  | Make text bigger.                                        | `?open=settings` | Text grew and nothing overlapped or was cut off.                              |
| S4  | Turn off notification sounds, then all notifications.    | `?open=settings` | Sounds are off; with notifications off, the sub-options are visibly disabled. |
| S5  | Choose the fastest model for agents.                     | `?open=settings` | Claude Haiku 5.5 has the checkmark.                                           |
| S6  | Start resetting all agents, then change your mind.       | `?open=settings` | The confirmation appeared, they cancelled, and nothing was reset.             |
| S7  | Find the setting for reducing transparency by searching. | `?open=settings` | They found it through search and turned it on.                                |

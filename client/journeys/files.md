# Files: key user journeys

Workspace file browser (placeholder data). Start at `http://localhost:6200/web.html?open=files`.

| Id  | Who / goal                                         | Starts at     | Done when                                                                                         |
| --- | -------------------------------------------------- | ------------- | ------------------------------------------------------------------------------------------------- |
| F1  | Find the refactor plan that the Coder agent wrote. | `?open=files` | They located `refactor-plan.md` and know which agent made it, and when.                           |
| F2  | Search for a file by part of its name.             | `?open=files` | Searching narrowed the list to the right file; clearing the search restored it.                   |
| F3  | Find where deleted files go.                       | `?open=files` | They found Recently Deleted.                                                                      |
| F4  | Browse files in a small window.                    | `?open=files` | At the smallest window size every row is readable, with long names truncated and nothing cut off. |

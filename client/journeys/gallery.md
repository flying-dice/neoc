# UI Kit: key user journeys

The living catalogue of `@agentos/ui`, for people building AgentOS apps. Start at
the host's address in a paired browser with gallery open.

| Id  | Who / goal                                                               | Starts at       | Done when                                                                         |
| --- | ------------------------------------------------------------------------ | --------------- | --------------------------------------------------------------------------------- |
| G1  | An app developer: find which button style to use for a secondary action. | UI Kit open | They found the button variants and picked "tinted" or "gray".                     |
| G2  | Check how components look in dark mode.                                  | UI Kit open | They switched the catalogue's appearance and compared.                            |
| G3  | Try a sheet and an alert, then dismiss each.                             | UI Kit open | Both opened and were dismissed in the expected way (Cancel, the scrim or Escape). |
| G4  | Find the system colours and the grays.                                   | UI Kit open | They can point to the colour swatches.                                            |

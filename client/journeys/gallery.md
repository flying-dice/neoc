# UI Kit: key user journeys

The living catalogue of `@agentos/ui`, for people building AgentOS apps. Start at
`http://localhost:6200/web.html?open=gallery`.

| Id  | Who / goal                                                               | Starts at       | Done when                                                                         |
| --- | ------------------------------------------------------------------------ | --------------- | --------------------------------------------------------------------------------- |
| G1  | An app developer: find which button style to use for a secondary action. | `?open=gallery` | They found the button variants and picked "tinted" or "gray".                     |
| G2  | Check how components look in dark mode.                                  | `?open=gallery` | They switched the catalogue's appearance and compared.                            |
| G3  | Try a sheet and an alert, then dismiss each.                             | `?open=gallery` | Both opened and were dismissed in the expected way (Cancel, the scrim or Escape). |
| G4  | Find the system colours and the grays.                                   | `?open=gallery` | They can point to the colour swatches.                                            |

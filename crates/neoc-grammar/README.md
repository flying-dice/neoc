# neoc-grammar

The tree-sitter grammar for neoc, plus the Rust `LANGUAGE` binding over it.

- `tree-sitter-neoc/grammar.js` is the grammar source. It mirrors `lang/SYNTAX.md`, which is the language definition.
- `tree-sitter-neoc/src/` is generated by `tree-sitter generate` and committed: `parser.c`, `grammar.json`, `node-types.json` and the `tree_sitter/` headers. `build.rs` compiles `parser.c` with `cc`.
- `tree-sitter-neoc/.gitignore` keeps tree-sitter build output (`*.wasm`, `*.so`, `build/`) and Node tooling (`node_modules/`) out of git.

## Changing the grammar

Prerequisite: tree-sitter CLI **v0.25.10**. That is the version stamped on line 1 of `src/parser.c`. Another version rewrites the generated files: a different patch release changes `parser.c`, and a different minor release also changes `grammar.json`, `node-types.json` and `tree_sitter/parser.h` and can change the parser ABI (`LANGUAGE_VERSION`). Run it with Node through `npx`; no global install is needed.

1. Edit `tree-sitter-neoc/grammar.js`. Update `lang/SYNTAX.md` in the same change.
2. Regenerate the parser:

   ```sh
   cd crates/neoc-grammar/tree-sitter-neoc
   npx tree-sitter-cli@0.25.10 generate
   ```

3. Commit `grammar.js` together with the regenerated files under `src/`. `git status` should show no other new files.
4. Run `cargo test -p neoc-grammar -p neoc-parser`, then the workspace suite.
